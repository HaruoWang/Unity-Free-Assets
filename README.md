## Polarith AI

### Get Started

1. Use AIM Context, AIM Seek & AIM Controller 2D to identify interest and danger objects.
2. Use AIM Planar Interpolation & AIM Stabilization to stabilize the tracing line. 
3. You can also **use the quick setup in AIM Context to do all of the above.**

<img alt="Unity Free Assets" src="/img/Polarith AI/Get Started.png">

### Perception Pipeline

1. Using AIM Environment, AIM Steering Perceiver, & AIM Steering Filter helps manage better and makes the copied object functional too.
2. You need to add these GameObject: EnvInterest, EnvDanger, and Perceiver.
3. **You need to adjust the setting of AIM Seek.**

<img alt="Unity Free Assets" src="/img/Polarith AI/Perception Pipeline.png">

### Dynamic and Static Environments

1. Making the AIM Environment static and using Update Environment can help improve performance.
